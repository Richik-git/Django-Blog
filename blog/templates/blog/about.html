About Blogarithm

A simple blogging platform built with Django.

Blogarithm is a full-stack web application where users can create, read, update and delete blog posts.

Users can create an account, manage their profile, publish posts and interact with posts through comments.

The application is powered by Django and PostgreSQL, with a REST API available for programmatic access.
